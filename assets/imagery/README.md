# NASA lunar visuals

These are original, unmodified JPEG assets linked from NASA's [Moon Phase and Libration, 2026](https://svs.gsfc.nasa.gov/5587/) page, under its named lunar phases. The named-phase files are reused by NASA across annual pages; the direct URLs retain the older visualization directory `a005048`.

| File | Description | Original source |
| --- | --- | --- |
| `moon-gibbous.jpg` | Waxing gibbous Moon, black background, 1024 × 1024. Recommended hero asset because its terminator shows relief. | [NASA original](https://svs.gsfc.nasa.gov/vis/a000000/a005000/a005048/phase_waxing_gibbous.2158_print.jpg) |
| `moon-full.jpg` | Full Moon, black background, 1024 × 1024. Alternate overview image. | [NASA original](https://svs.gsfc.nasa.gov/vis/a000000/a005000/a005048/phase_full.1571_print.jpg) |

**Credit: NASA Scientific Visualization Studio.** The NASA page identifies Ernie Wright as visualizer and lists LRO LOLA elevation, LROC WAC imagery, and ephemerides as visualization inputs.

These assets are NASA-produced scientific visualizations derived from mission data, not a single telescope or spacecraft photograph. In LunaMargin they provide editorial context; they do not show the application's selected date or an exact landing-footprint view. No image-generation model or local image editing was used. File sizes and SHA-256 checksums are recorded in [sources.json](sources.json).

NASA's [media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/) allow factual educational/informational use with acknowledgement and without implying NASA endorsement. NASA insignia are not included in these files.
