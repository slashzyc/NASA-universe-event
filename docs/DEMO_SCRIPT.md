# LunaMargin — suggested three-minute demonstration

This is a proposed three-minute storytelling format, **not an official NASA video-length requirement**. Check the current submission guide before recording. Rehearse against the final application, match actual control labels and remove unavailable steps.

No measured value is supplied here. Use one saved, verified comparison and keep its evidence available.

## English narration

| Time | Screen action | Narration |
| --- | --- | --- |
| 0:00–0:25 | Open selected site/date. | “A lunar landing site is also a choice of time. Near the south pole, terrain can hide a low Sun or Earth. For a mission, the question is how long those interruptions last, and how much room the plan leaves when the touchdown point changes. This is LunaMargin.” |
| 0:25–0:55 | Show Sun, Earth and terrain horizon. Advance time. | “Here is the view from our selected reference point. The Sun and Earth positions come from NASA/JPL Horizons. The terrain comes from NASA LOLA. Moving through time connects the horizon to the visibility windows below. The source panel records the inputs behind this view.” |
| 0:55–1:25 | Show interruption metrics; change a supported threshold. | “We set the longest interruptions our concept is prepared to bridge. LunaMargin compares those thresholds with the modeled Sun-unavailable and Earth-unavailable intervals. For this saved case, the longest intervals are [verified values]. The margins show where this concept meets its assumptions and where a constraint is exceeded.” |
| 1:25–1:55 | Show nearby valid sample points and statuses. | “Now we examine nearby points. One reference location does not describe the entire surrounding area. Here, [passing count] of [valid count] evaluated points meet the chosen criteria. That is a fraction of tested points, not a landing-success probability. The sample layout and coverage are part of the result.” |
| 1:55–2:25 | Compare a second verified site/date. | “We can change the date or compare another point. With the same assumptions, this alternative [observed improvement, tradeoff or no improvement]. The comparison makes the choice inspectable: we can see which interval and which constraint drive it.” |
| 2:25–2:50 | Open provenance and saved export/report. | “Every comparison should travel with its evidence: coordinates, time window, sample spacing, source files and settings. This report lets someone repeat the case and question the assumptions. Geometric visibility supports early planning; electrical power and radio performance need additional engineering models.” |
| 2:50–3:00 | Return to the comparison. | “LunaMargin turns lunar data into a question people can explore: where, when, and with how much margin? The source and evidence are available with the project.” |

## 中文旁白

| 时间 | 画面操作 | 旁白 |

| 0:00–0:25 | 打开选定参考点与日期。 | “选一个月球落点，也是在选择一个时间。南极低角度的太阳与地球可能被地形遮住。任务需要知道中断持续多久，也需要知道落点稍有变化时还有多少余量。这就是 LunaMargin，月面余量。” |
| 0:25–0:55 | 展示太阳、地球和当地地平线，推进时间。 | “这里是选定位置看到的天空。太阳和地球的位置来自 NASA/JPL Horizons，地形来自 NASA LOLA。沿时间移动，能看到地平线如何对应下面的可见窗口。来源面板记录了这里使用的数据。” |
| 0:55–1:25 | 展示最长中断，调整已实现的约束。 | “我们输入任务概念可以跨过的最长中断时间。程序将它与连续断光和地球不可见时段比较。这个案例中，最长时段分别是［已核对的数值］。余量告诉我们哪些假设满足、哪一项约束被超过。” |
| 1:25–1:55 | 展示周围有效取样点。 | “接下来检查附近取样点。一个中心点无法代表整片区域。在本次设置下，［有效数量］个有效点中，有［通过数量］个符合条件。这是被检查点的比例，不能当作着陆成功概率。取样布局和数据覆盖一起决定了它的含义。” |
| 1:55–2:25 | 比较另一个已验证地点或日期。 | “换一个日期或参考点，保持其他假设一致。这次比较显示［实际改善、权衡或没有改善］。我们能直接看到，是哪个时段、哪项约束改变了选择。” |
| 2:25–2:50 | 打开来源与报告。 | “坐标、时段、步长、数据文件和计算设置都应该随结果保存。其他人可以据此复现和检查。几何可见性适合早期比较，真正的发电和通信性能还需要设备与链路模型。” |
| 2:50–3:00 | 回到比较画面。 | “月面余量让复杂月球数据变成三个可以探索的问题：在哪里、什么时候、还剩多少余量。项目提供源代码与结果依据。” |

## Recording checks

- Use actual exported results. Do not insert attractive invented figures.
- Keep coordinates, units, UTC times, thresholds and data mode legible.
- Identify bundled/precomputed data as such; do not call it a live NASA request.
- After changing settings, wait for current results before narrating them.
- Use captions and readable contrast; label statuses with words as well as color.
- Record the actual application. Visibly label inserted concept animations and AI-generated images/video.
- Add a development/AI credit or accompanying description linking [AI_DISCLOSURE.md](AI_DISCLOSURE.md), including the advance-work timeline.
- Check the official video-length and public-link requirements; this script does not establish them.
