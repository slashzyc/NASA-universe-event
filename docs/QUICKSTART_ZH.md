# LunaMargin 中文操作指南

这个项目帮助你回答：**看起来不错的月球落点，偏到旁边之后，光照和对地几何可见窗口还能满足任务条件吗？**

## 五分钟看懂

1. 从首页进入导航仪，点击“从示例开始”。这会载入连接脊 6、2027 年 6 月 2 日 06:00 UTC、停留七天的完整案例。右上角可以切换中英文；“教我怎么用”有四步说明。
2. 先看暖白色结果卡：中心点满足条件，但九个位置中只有八个满足。中心最长约 12.45 小时看不见太阳。前面三个数字描述当前点，最后一个数字统计整组九点。
3. 点击“查看东南未通过点”，或者地图下方九宫格的“东南”。它位于中心东侧 25 米、南侧 25 米，最长约 167.5 小时看不见太阳，有两项条件未满足。再点“中心”，就能直接比较。手机点选区也会即时显示简短结果。
4. 点击“帮我找更晚的日期”。系统在当前月份内每隔六小时检查一个抵达时间，寻找全部九点均满足条件的窗口。点击“使用这个窗口”即可应用。
5. 想试自己的任务时，选择“7 天探索”“3 天短访”，或改抵达日期。预设是练习条件；“自己设置”可展开更多参数。修改后点击“查看任务结果”更新，提示会明确告诉你结果是否已更新。所有日期采用 UTC。
6. 想看原因，展开“看看为什么 · 光照与地平线”，拖动时间滑块。彩色时间条表示可见，深色空白表示被挡住。
7. “保存这份简报”直接下载可阅读的 HTML；“下载结果”还可保存 CSV 对比表与 JSON 完整记录。HTML 可以用浏览器打开并打印为 PDF。
8. 首页九点演示选中哪个位置，“查看完整案例”就会带入那个位置和当前语言。保存后想复查，在结果卡展开“计算版本与已保存记录”，打开 JSON 文件；原版可用时恢复原计算，版本缺失时先保留旧结果，再由你决定是否用当前版本重新计算。

## 三个最重要的概念

- **最长连续断光**：所选任务区间内，太阳中心被地形挡住的最长连续时长。它可能从任务前延续而来，也可能在任务结束后继续。
- **最长地球不可见**：地球中心被挡住的最长时间；实际通信还需要地面站、天线和链路预算。
- **周边通过数**：九个离散位置中，多少满足你输入的全部条件。8/9 不是 88.9% 的着陆成功率。

## 本地启动

电脑安装 Node.js 20 或更新版本后，在项目文件夹打开终端，输入：

```sh
node scripts/serve.mjs
```

浏览器打开 `http://127.0.0.1:4173`。使用期间保留终端窗口，完成后按 Ctrl+C 结束。无需安装其他前端软件包，无需 API 密钥。
