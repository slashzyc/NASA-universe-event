# LunaMargin 中文操作指南

这个项目帮助你回答：**看起来不错的月球落点，偏到旁边之后，光照和对地几何可见窗口还能满足任务条件吗？**

## 五分钟看懂

1. 打开应用，点击右上角“中文”。默认展示 2027 年 6 月 2 日 06:00 UTC、持续七天的研究案例。
2. 保持 ROI 6。中心点的最长断光约 12.45 小时，九个位置中八个满足所设条件。
3. 点击地图右侧放大框中的右下角点：东 25 米、南 25 米。现在指标、地平线、时间条会显示这个位置。它的模型断光显著增加。
4. 拖动时间滑块，看太阳和地球如何经过地形地平线。黄色是太阳，蓝色是地球；虚线代表你设置的额外角度余量。
5. 点击“寻找更晚的可行窗口”。系统会在当前月份中搜索中心与九个样本均满足条件的日期，点击结果可直接应用。
6. “导出证据”可以保存 HTML 任务简报、CSV 对比表和 JSON 完整记录。HTML 可以直接用浏览器打开并打印为 PDF。

## 三个最重要的概念

- **最长连续断光**：所选任务区间内，太阳中心被地形挡住的最长连续时长。它可能从任务前延续而来，也可能在任务结束后继续。
- **最长地球不可见**：地球中心被挡住的最长时间；实际通信还需要地面站、天线和链路预算。
- **周边通过数**：九个离散位置中，多少满足你输入的全部条件。8/9 不是 88.9% 的着陆成功率。

## 本地启动

电脑安装 Node.js 20 或更新版本后，在项目文件夹打开终端，输入：

```sh
node scripts/serve.mjs
```

浏览器打开 `http://127.0.0.1:4173`。使用期间保留终端窗口，完成后按 Ctrl+C 结束。无需安装其他前端软件包，无需 API 密钥。
