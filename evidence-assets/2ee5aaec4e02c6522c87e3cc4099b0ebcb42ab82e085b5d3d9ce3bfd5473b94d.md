## 运行和部署状态

- **完整服务**：在项目目录执行 `node scripts/build.mjs`、`node server/index.mjs`，打开 `http://127.0.0.1:4173/`。要求 Node.js 24+，服务端不需要额外 npm 包。
- **持久数据**：默认 `var/lunamargin.sqlite`；NASA 原响应与新数据位于 `var/horizons/`；不可变版本快照位于 `var/evidence-assets/`。完整保留 `var/`，重启后任务仍在。
- **公开地址**：<https://slashzyc.github.io/NASA-universe-event/> 是静态前端预览，显示数据库未连接。它不提供线上保存。现有私有 Sites 镜像同样是静态前端。
- **线上完整服务缺项**：持续运行 Node.js 24 的主机、持久磁盘、HTTPS 域名/反向代理、备份与维护配置。当前没有将本地接口冒充线上接口。已提供 Docker 配置，但本机没有执行 Docker 构建验收。
- 操作、数据库、接口和部署细节见 [服务说明](SERVICE_DEPLOYMENT.md)。

## 实际录制与一致性检查

[观看完整操作录制](media/lunamargin-explorer-flow.webm)。录像来自真实构建页面和真实 Node 服务，不是界面样片。依次完成拖动月球、选择连接脊、进入工作台、提交条件、将断光阈值改为 8 小时、比较两个方案、保存、关闭服务、显示连接错误、启动新服务进程、恢复任务、清除当前访客身份后通过只读链接打开、导出 JSON 和报告。

验证脚本直接比对保存接口、页面所显示的完整记录、SQLite 中的 JSON 正文和下载的 JSON，四者一致；HTML 检查所用阈值及版本摘要。另一个访客访问原任务编辑接口得到 404。[边界场景 6 项](explorer-edge-validation.json) 另检查重命名与删除失败反馈、复制、三方案上限、首次断连的分享恢复，以及短任务保留更高门槛。未知地点、超覆盖日期和 5 m 高度得到 422，不生成正式结果。

新日期验收复用本轮实际下载的 2027-07-01 至 07-03 NASA 响应，完成 48 小时计算、保存、刷新、重启、手机只读分享和导出。断光 21.6710407737 h、共同可见 26.3289592263 h 来自连接脊 6 的真实输入。单独的上游 HTTP 400 是明确标记的失败注入，仅检查错误界面，不产生科学结果。

## 性能与设备范围

在当前 Windows 电脑、Chrome、本地 HTTP、真实 `dist/` 上测量；手机检查使用 390×844 触控模拟，包含真实浏览器触摸与双指事件，**未声称真机实测**。数值记录在上面的 JSON 中。首次球体可操作约 0.3–0.5 秒，进入工作台含准备及动画约 0.9–1.0 秒。完整移动端首次计算约 1–1.7 秒。公网、慢网和实际低端手机速度可能不同。

桌面和手机核心流程无横向溢出或应用脚本异常；关闭 WebGL、纹理加载失败、减少动态效果、被动滚轮页面滚动均经过检查。首屏球体美术照明与任务日期无关；工作台方向和可见性来自同一组坐标、时刻与已校验数据。

## 复现

```sh
npm ci
node scripts/build.mjs
node --test tests/*.test.js
node tests/revision-browser.mjs
node tests/round2-entry-browser.mjs
node tests/round2-version-browser.mjs
node tests/explorer-flow-browser.mjs
```

前三个旧浏览器脚本沿用各自的静态服务器设置；完整流程脚本自行启动、关闭并重新启动真实服务。球体脚本使用 `LUNAMARGIN_URL` 指定构建预览地址。新日期脚本要求显式准备真实 NASA 缓存，见 [数据管线复现](DATA_PIPELINE.md)。录制需要 Playwright 官方 FFmpeg；浏览器依赖仅用于验收，不是运行服务的依赖。

## 保留的科学范围

目前是连接脊三个相邻研究点、27 个离散取样位置、2 m 高度；不是全球任意位置的着陆分析。地形像素间距为 5 m / 80 m，星历通常为 30 分钟；附近点复用中心星历，地形地平线独立。几何可见性不等于供电或可用通信链路。真人研究、正式赛事提交和奖项资格仍按已有记录分别管理，本轮功能验收不代表它们已完成。
