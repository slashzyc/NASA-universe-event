# LunaMargin 中文操作指南

主要用途是早期月球任务概念设计中的地点与日期比较，教育演示为辅助。这个项目帮助你回答：**看起来不错的月球落点，偏到旁边之后，光照和对地几何可见窗口还能满足任务条件吗？**

## 五分钟看懂

完整体验从可拖动的三维月球开始：点击“定位南极”，选择连接脊研究点，再点击“进入分析”。月球上的阴影是美术照明，实际结果使用任务日期对应的 NASA 星历。

打开 [在线工作台](https://lunamargin-slashzyc.laceysquirrel4.chatgpt.site/?lang=zh)，显示“任务数据库已连接”后，点击“计算并记录”。把结果“加入方案对比”，改日期或阈值，再计算并加入第二个方案。点击“保存任务”为它命名，在“我的任务”中查看原结果、复制、重命名、删除或生成只读链接。“使用当前版本新建计算”保留原证据，另外创建新结果。“导出正式记录”使用数据库中保存的完整结果。

“数据覆盖与新日期”列出可用日期和 2 米高度；本地 Node 完整服务可申请 2026–2028 年范围内的新日期，先查缓存，再按顺序请求 NASA，显示实际状态。云端目前只提供三组已验证日期，不提供新日期队列。仅支持已有地形的离散取样位置。

[GitHub Pages](https://slashzyc.github.io/NASA-universe-event/?lang=zh) 提供浏览器计算和设备文件模式：可直接加入比较，点击“保存到设备”命名并下载完整 JSON 文件，再用“打开已保存文件”恢复。文件中的参数、结果与数据版本会被核对。它与在线工作台中的“保存到服务器”分别管理。

1. 从首页进入导航仪，点击“从示例开始”。这会载入连接脊 6、2027 年 6 月 2 日 06:00 UTC、停留七天的完整案例。右上角可以切换中英文；“教我怎么用”有四步说明。
2. 先看暖白色结果卡：中心点满足条件，但九个位置中只有八个满足。中心最长约 12.45 小时看不见太阳。前面三个数字描述当前点，最后一个数字统计整组九点。
3. 点击“查看东南未通过点”，或者地图下方九宫格的“东南”。它位于中心东侧 25 米、南侧 25 米，最长约 167.5 小时看不见太阳，有两项条件未满足。再点“中心”，就能直接比较。手机点选区也会即时显示简短结果。
4. 点击“帮我找更晚的日期”。先确认最大允许推迟时间与排序偏好。新任务的 72 小时等待预算和 24/24/24 小时门槛均为练习假设。系统只在允许抵达范围及完整数据覆盖内，每隔六小时检查一个抵达时间；可优先最早满足条件，或优先九点最弱余量。不得把未检查的日期称作无解。点击“使用这个窗口”即可应用。
5. 想试自己的任务时，选择“7 天探索”“3 天短访”，或改抵达日期。预设是练习条件；“自己设置”可展开更多参数。修改后点击“查看任务结果”更新，提示会明确告诉你结果是否已更新。所有日期采用 UTC。
6. 想看原因，展开“看看为什么 · 光照与地平线”，拖动时间滑块。彩色时间条表示可见，深色空白表示被挡住。
7. “保存这份简报”直接下载可阅读的 HTML；“下载结果”还可保存 CSV 对比表与 JSON 完整记录。HTML 可以用浏览器打开并打印为 PDF。
8. 首页九点演示选中哪个位置，“查看完整案例”就会带入那个位置和当前语言。保存后想复查，在结果卡展开“计算版本与已保存记录”，打开 JSON 文件；原版可用时恢复原计算，版本缺失时先保留旧结果，再由你决定是否用当前版本重新计算。

## 三个最重要的概念

- **最长连续断光**：所选任务区间内，太阳中心被地形挡住的最长连续时长。它可能从任务前延续而来，也可能在任务结束后继续。
- **最长地球不可见**：地球中心被挡住的最长时间；实际通信还需要地面站、天线和链路预算。
- **周边通过数**：九个离散位置中，多少满足你输入的全部条件。8/9 不是 88.9% 的着陆成功率。

## 本地启动

电脑安装 Node.js 24 或更新版本后，在项目文件夹打开终端，输入：

```sh
node scripts/build.mjs
node server/index.mjs
```

浏览器打开 `http://127.0.0.1:4173`。使用期间保留终端窗口，完成后按 Ctrl+C 结束。无需安装其他前端软件包，无需 API 密钥。

任务数据库保存在 `var/lunamargin.sqlite`；请保留整个 `var/` 文件夹。关闭服务后重新运行第二条命令即可恢复。保留浏览器 Cookie，才能继续使用自己的匿名编辑身份；只读链接接收者不能修改原任务。[完整部署说明](SERVICE_DEPLOYMENT.md)。

## 比赛展示

先讲一个具体问题：**“平均日照 92.6% 的中心点，是否代表附近也同样好？”** 接着演示右下角取样位置，核对允许抵达范围，再比较 ROI 1 / ROI 4 的名义判断和已完成复核。6 月 21 日推荐相对默认案例晚 462 小时，必须由使用者明确允许这么长的推迟；默认 72 小时范围不会给出该方案。最后导出来源可追溯的证据。全部展示数字以当前运行结果为准。
